# Oasis Infobyte - Web Development Internship (Level 1 - Task 2)

## Project: Personal Portfolio Website

### 📌 Overview
This project is a personal portfolio website developed as part of the **Oasis Infobyte Web Development and Designing Internship (OIBSIP)**. It serves as a professional showcase of my skills, projects, education, and contact information.

### 🚀 Features
- **About Me Section:** Brief introduction about background, education, and career interests.
- **Skills Section:** Highlights technical proficiencies (HTML, CSS, JavaScript, etc.).
- **Projects Section:** Showcases completed web development tasks and works.
- **Contact Section:** Provides a way for visitors to get in touch.
- **Fully Responsive:** Adapts seamlessly to various screen sizes and devices.

### 🛠️ Technologies Used
- **HTML5** – For structuring the portfolio sections
- **CSS3** – For modern styling, animations, and responsive layouts
- **JavaScript** – For interactive elements and functionality

### 📂 How to View
1. Open the repository folder.
2. Locate and open the `Web-Dev-L1-Task2-Personal-Portfolio` directory.
3. Double-click on `index.html` to view the website in any web browser.
