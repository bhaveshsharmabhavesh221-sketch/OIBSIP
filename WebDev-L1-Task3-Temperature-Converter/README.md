# Oasis Infobyte - Web Development Internship (Level 1 - Task 3)

## Project: Temperature Converter Website

### 📌 Overview
This project is a functional **Temperature Converter web application** built as part of the **Oasis Infobyte Web Development and Designing Internship (OIBSIP)**. It allows users to convert temperature values seamlessly between Celsius, Fahrenheit, and Kelvin scales with real-time computation.

### 🚀 Features
- **Multi-Unit Conversion:** Convert values between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
- **Interactive UI:** Clean, user-friendly interface with input fields and clear output display.
- **Dynamic Calculation:** Instantly processes user input and calculates the converted temperatures using JavaScript logic.
- **Responsive Layout:** Designed to work smoothly across desktops, tablets, and mobile devices.

### 🛠️ Technologies Used
- **HTML5** – For structuring the conversion form and layout elements
- **CSS3** – For styling, centering, colors, and responsive design
- **JavaScript** – For handling mathematical temperature conversion formulas and DOM manipulation

### 📂 How to View
1. Open the repository folder.
2. Locate the `Web-Dev-L1-Task3-Temperature-Converter` directory.
3. Double-click on `temp_converter.html` (or `index.html`) to open and run the application in any web browser.
