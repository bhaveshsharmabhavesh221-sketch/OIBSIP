# Oasis Infobyte - Web Development Internship (Level 1 - Task 1)

## Project: Responsive Bike Landing Page

### 📌 Overview
This project is a modern, responsive landing page created as part of the **Oasis Infobyte Web Development and Designing Internship (OIBSIP)**. The landing page showcases a sleek design with smooth navigation, attractive layout, and user-friendly interface.

### 🚀 Features
- **Responsive Design:** Works smoothly on desktop, tablet, and mobile screens.
- **Modern UI/UX:** Clean layout with well-structured sections (Header, Hero Section, Features, Models/Gallery, Contact/Footer).
- **Interactive Elements:** Hover effects and smooth scrolling.

### 🛠️ Technologies Used
- **HTML5** – For webpage structure
- **CSS3** – For styling, layout (Flexbox/Grid), and responsiveness

### 📂 How to View
1. Download or clone this repository.
2. Open the `Web-Dev-L1-LandingPage` folder.
3. Double-click on `index.html` to open it in any web browser.
